# Lanz Aceveda | Personal Interface

A responsive portfolio for a BS Information Technology student. Built with HTML, CSS, and vanilla JavaScript; no build process or package installation is needed.

## Run locally

Open `index.html` with VS Code Live Server, or serve this folder with a static web server.

## Customize

- Replace the profile, project, and certificate artwork in `images/`.
- Edit the personal details, biography, skill labels, project descriptions, and archive records in `index.html`.
- Replace each project repository and demo `href="#"` with its project-specific URL.
- The GitHub and LinkedIn links use the supplied profile URLs.
- The contact form uses a `mailto:` handoff to `lanzjireh67@gmail.com`; it prepares a draft and does not send messages on its own.
- Replace `EDITABLE` skill labels with accurate self-assessments.

Google Fonts and Font Awesome load from their CDNs. All other assets are local.
